# 스도쿠 아레나
로그인 없이 초대 링크로 즐기는 2–4인 실시간 스도쿠. 기본값: 스피드 배틀 / 보통 / 비공개 초대방.

- 스피드 배틀: 같은 퍼즐을 먼저 완성하면 승리
- 점수 쟁탈전: 5분 또는 첫 완성까지, 정답 +10 / 오답 -2, 최고점 승리 (동점 공동 1위)
- 영역 점령전: 한 판에서 순서대로 칸 점령, 정답 +10 / 오답 -2, 차례 넘기기 지원
- 난이도 3단계, 유일해 퍼즐, 서버 정답 판정, 최대 4명, 대기실/게임 채팅
- 모바일 숫자패드와 PC 숫자키 입력, 재접속 토큰, 방장 설정 동기화

## 실행
Node.js 20 이상. `npm ci` 후 `npm start`. 기본 포트 3000, PORT 환경변수 지원.
`npm test`로 퍼즐/승패 로직 검사. `node multiplayer.test-run.js http://localhost:3000`으로 4인 WebSocket 통합 검사.

## Render
Web Service / Node / Free / Build: `npm ci` / Start: `npm start` / Health: `/health`.
방/채팅은 메모리 저장. 서버 재시작 시 소실되고, 비활성 무료 서버는 최초 접속에 지연이 발생할 수 있습니다.
초대방은 무작위 링크 기반이며 별도 계정/비밀번호는 없습니다. 링크를 공개하면 누구나 입장할 수 있습니다.
